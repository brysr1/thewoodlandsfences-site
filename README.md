# thewoodlandsfences.com

Jekyll site for 76 Fence of The Woodlands, hosted on GitHub Pages.

Pages are Markdown/HTML in the repo root, `service-areas/`, `materials/`, and `fence-styles/`. Business details (NAP, hours, booking link, form endpoint) live in `_config.yml`; navigation in `_data/navigation.yml`; reviews in `_data/testimonials.yml`.
